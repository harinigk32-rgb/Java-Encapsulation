# Java-Encapsulation
OOPS Concept - Encapsulation program
About the Project

This project demonstrates Encapsulation, one of the four fundamental principles of Object-Oriented Programming (OOP) in Java.

Concepts Covered

Classes and Objects

Private data members

Getters and Setters

Data Hiding

this keyword

Methods and Constructors

Technologies Used

Java

IntelliJ IDEA

Project Objective

To understand how encapsulation protects data by restricting direct access to class variables and providing controlled access through methods.
